# 🌍 Simulador de Gerenciamento da COP-31
Este projeto consiste no desenvolvimento de uma aplicação gráfica semelhante ao clássico Microsoft Paint, com foco na compreensão prática de conceitos fundamentais de programação gráfica e interação com o mouse.

## Funcionalidades
- 🌎 Gestão de Países

  - Consumo da API REST Countries

  - Listagem de países participantes

  - Filtro e busca dinâmica

- 👤 Gestão de Autoridades

  - Cadastro de autoridades

  - Aplicação de regras de negócio

  - Persistência de dados via localStorage

  - Edição e remoção de registros

- 🗓️ Gestão de Agenda

  - Agendamento de apresentações

  - Controle de conflitos de horário

  - Associação entre países e autoridades

## Tecnologias Utilizadas
- ⚛️ React
- 🟦 TypeScript
- ⚡ Vite
- 🌍 API pública REST Countries
- 💾 localStorage

## Como executar
```
git clone https://github.com/dev-pedr0/cop-30
cd nome-do-projeto
npm install
npm run dev
```
